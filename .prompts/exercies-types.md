# Exercises types

I have 4 types of exercises:

1. Reps and weigth (bench press)
2. Reps and difficulty (band assisted pullups)
3. Time and weigth (grip holds)
4. Time and difficulty (plank)

We need to consider each of these in the program editor, in particular when you add an exercise to a day, since right now it gives you only the posiblity to set the sets and reps, it should ask the sets and the convenient option between weigth and difficulty.
